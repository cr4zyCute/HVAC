# NorthStar HVAC — Figma Design Package

Welcome to the designer's edition of the NorthStar HVAC Design System!

---

## 📁 Package Contents

* **`desktop-1440/`**: 10 Desktop screens (1440px wide) designed on an 8px grid system.
* **`tablet-834/`**: 10 Tablet responsive screens (834px wide).
* **`mobile-390/`**: 10 Mobile responsive screens (390px wide).
* **`design-system/`**: 
  * `components-library.svg`: Full UI kit containing buttons, inputs, Lucide icons, badges, and alerts.
  * `figma-design-tokens.json`: Raw design tokens format for Figma Tokens Studio / Style Dictionary.

---

## 🔤 Required Free Google Fonts

Before opening in Figma, ensure you have the following free Google Fonts installed:
1. **[Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)** (Weights: 600, 700, 800)
2. **[Inter](https://fonts.google.com/specimen/Inter)** (Weights: 400, 500, 600, 700)

---

## 🚀 How to Import into Figma

1. Open your Figma desktop app or browser workspace.
2. Create a new design file.
3. Simply drag and drop any `.svg` file from `desktop-1440/`, `tablet-834/`, or `mobile-390/` directly onto your Figma canvas.
4. All layers will import with editable text, precise auto-layout bounds, and vector strokes.
